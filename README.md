# Pedido de Namoro

Projeto desenvolvido com HTML, CSS e JavaScript para criar uma experiência interativa e divertida de pedido de namoro.

A aplicação simula uma página romântica com animações, interações dinâmicas e efeitos visuais voltados para uma experiência leve, criativa e personalizada.

---

## Funcionalidades

- Interface interativa
- Botões com comportamento dinâmico
- Animações em CSS
- Efeitos visuais personalizados
- Layout responsivo
- Interações utilizando JavaScript
- Design temático romântico

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
